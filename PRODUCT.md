# Product

## Register

product

## Users

A single developer using J.A.R.V.I.S. personally in a desktop browser.

## Product Purpose

Provide a proof-of-concept voice assistant that continuously listens for “Hey Jarvis” with openWakeWord, transcribes commands locally with NVIDIA Nemotron Speech Streaming EN 0.6B, sends text to an OpenRouter model, and generates local speech with Kokoro-82M.

## Brand Personality

No defined brand personality for the MVP. The interface should be direct and functional.

## Anti-references

No explicit visual references or anti-references. Avoid unnecessary decoration and assistant-themed novelty.

## Design Principles

- Make the end-to-end voice loop work before adding features.
- Keep local processing and remote processing boundaries clear.
- Show the assistant’s current state plainly.
- Prefer a small, understandable implementation over abstraction.

## Accessibility & Inclusion

No formal accessibility target for the proof of concept.
